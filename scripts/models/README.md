Complex test models, built in code. Run from this folder: `python3 gen.py stl` writes the first set into `stl/`,
then `python3 genN.py` (2-9) add the rest (wardrobe, trestle, oval table, mitred box, picture frame, hutch desk,
face-frame base, garden bench, step stool, L desk, sliding-door console). Compare guides between commits with
`scripts/guide-diff.sh <folder-of-stl> [ref]`.
